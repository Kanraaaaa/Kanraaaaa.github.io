🧭 本周观察

Agent 的效率开始从模型单点指标走向整个工作流：针对 harness 做后训练，以截图筛选小模型操作，把 rollout 与权重刷新一起调度，再用独立质量检查验收基础设施优化。国产栈方面，Xing4 披露了 Ascend 910C 上的大规模训练路径，SGLang NPU 算子库则持续修补图捕获、构建和接口兼容。

解读与建议　CANN 社区可以把“成功任务成本”与“整网有效加速”放在同一验收表里：记录硬件、镜像、工具调用、精度及策略版本。训练报告、算子合入与推理框架支持是不同证据，本期分别呈现。
阅读口径　“已核事实”表示原始来源确有此陈述，不表示本文独立复现；“为何关注”为编辑解读，“CANN 启发”为迁移建议或推断。

🤖 AI Agent / Agentic

External sandboxes：把执行环境从 Agent 中分离

2026-11-16 · 一手工程实践

已核事实　Simon Willison 与 Prime Radiant 发布三种共享 localhost API 的沙箱原型：v86/WebAssembly、Apple Containers、Quicksand/QEMU。Agent 在外部发命令，沙箱限制挂载和网络；但 Claude Code 接入只隔离 Bash，原生 Read/Edit 仍在宿主机执行。
为何关注　接入了沙箱不等于所有工具都被隔离。文章逐项交代不同 Agent 的覆盖面，并提供协议及一致性测试，适合核对真实执行边界。
CANN 启发（推断/建议）　可给昇腾调优 Agent 的编译与测试工具定义统一远程执行接口；设备节点、数据目录及凭证应单独授权。文中原型未核实可直接挂载 NPU。

Harness adapters：针对实际工具链做 RL

2026-11-20 · 官方研究博客

已核事实　Hugging Face 为 Qwen3.8-27B 在 Pi、OpenCode、Hermes 中分别训练 LoRA，并公开任务、轨迹与合并适配器。文章在固定 harness 内报告成功率和工具调用改善，也明确不同 harness 的压缩策略不同，不能直接横比。
为何关注　Agent 能力由模型、工具与控制流程共同决定。合并权重在 Terminal-Bench 上选择，因此该基准结果略乐观；单 harness、关闭 thinking 时专用适配器通常更强。
CANN 启发（推断/建议）　可围绕 Ascend C 编译、精度验证和 profiler 工具收集任务，再评估专用 LoRA；按成功任务统计调用数、token 和上板时间。这是迁移建议，原文未证明 Ascend 训练支持。

Vanguard：用截图判断小模型草稿是否可用

2026-11-18 · arXiv 预印本

已核事实　作者提出无需修改草稿与目标模型的步骤级判别器：读取截图，为候选操作打分，超过阈值则采用，否则交给大模型。在网页、手机和具身任务上，2B 草稿配判别器至少达到所测 8B 目标的准确率。
为何关注　这是任务步骤级的选择机制，可以与 token 级投机解码组合；它会改变操作选择，不能等同于保持目标分布的无损解码。结果仍限于作者评测。
CANN 启发（推断/建议）　昇腾 GUI/运维 Agent 可比较小模型草稿、视觉判别和大模型回退的总时延，额外测误接受率及阈值跨界面迁移。

🧠 LLM 训练与推理

SWE-OPD：在学生实际访问的轨迹上蒸馏

2026-11-16 · arXiv 预印本

已核事实　学生在可执行仓库中行动，教师监督学生访问的前缀。作者报告 Qwen3.5-9B 的 SWE-bench Pro 解决率由 35.9% 升至 39.4%；缓存教师评分的离线变体减少 59.4%–72.6% GPU-hours，但准确率随基准变化。
为何关注　更低训练损失并不保证 Agent 更好：论文还观察到损失下降而重复输出加重。离线复用有成本价值，也必须单独验收长轨迹行为。
CANN 启发（推断/建议）　可将昇腾小模型后训练中的教师打分与学生 rollout 分开计费；同时检查任务解决率、重复循环和轨迹新鲜度，不把 GPU-hours 降幅直接换算为 NPU 收益。

QDA：量化配方搜索加入隐藏评估与长生成检查

2026-11-17 · arXiv 预印本

已核事实　Agent 组合兼容的 PTQ 方法，用其不可见的推理轨迹上输出 KL 快速筛选，再以长生成检查候选。作者在四种推理模型上报告 W4A16、W4A8、W3A16 平均准确率分别高于最强公开配方 0.9、1.4、2.2 个百分点，每次搜索耗用 64 GPU-hours。
为何关注　量化自动搜索既需要便宜的代理指标，也需要能捕获重复循环的真实生成验收。论文承诺开放库、评估器和 harness，不能将承诺写成已完整开源。
CANN 启发（推断/建议）　先把 CANN 已有低比特 kernel 支持作为配方约束，再搜索校准策略。NVFP4 等论文配置不等于昇腾已支持，须逐芯片核对量化格式与执行路径。

Dynamo：把 rollout、权重刷新与恢复一起优化

2026-11-19 · 官方技术博客

已核事实　NVIDIA 说明 Dynamo 的 KV 感知路由在缓存复用和排队间取舍，ModelExpress 从集群已有副本加载权重并传输增量；RL 框架仍负责权重切换时机、缓存处理和样本接纳。恢复路径依赖具体支持配置。
为何关注　RL 的有效吞吐不能仅看生成 token/s。样本是否使用正确策略版本、故障后保留多少 rollout、权重更新时间都可能决定整轮训练速度。厂商案例并非统一基准。
CANN 启发（推断/建议）　昇腾异步 RL 可分别记录有效样本/秒、权重版本滞后、刷新停顿和故障重做量，再比较路由与权重传输方案。文中 NIXL/GPU 路径不能直接当作 CANN 能力。

GPT-6.2 Astra / Sol：模型更新与后台完成窗口

2026-11-17 · 官方变更日志

已核事实　OpenAI API 变更日志列出 GPT-6.2 Astra 与 Sol，两者支持 Responses 与 Chat Completions，工具调用要求 Responses。同期公开测试的后台完成窗口提供两小时与八小时选项，相对 Standard 的模型 token 费率分别低 30% 和 40%。
为何关注　交互任务与宽松期限任务开始有不同的服务选择。折扣针对模型 token 费率，不能理解为整个 Agent 任务费用同比下降，也不能与即时完成混为一谈。
CANN 启发（推断/建议）　周报、离线评测和算子搜索可按截止时间分队列，在昇腾服务中比较即时调度与批量调度的利用率、完成率和成本。未核实这些闭源模型的 CANN 部署支持。

🛠️ 开发者工具

GitHub CLI：用事件流等待 PR 变化

2026-11-18 · 官方变更日志

已核事实　gh v2.105.0 新增 gh event listen，按行输出 PR 事件 JSON，默认首个事件后退出，支持 count、follow 和 timeout。命令与 Event Streams 均为预览，GitHub.com 用户需先获 Event Streams 访问资格。
为何关注　评审、head 变化与检查完成可成为 Agent 的明确唤醒条件。使用前仍需处理超时和预览资格，不能把它写成所有账户立即可用。
CANN 启发（推断/建议）　昇腾适配 PR 的 CI 和评审跟踪可从固定轮询转为事件驱动，收到 head 变化后重置验收依据，并为漏事件设计状态核对。

Datasette Lite：用 URL 分享可复现的 Python 环境

2026-11-17 · 一手工程实践

已核事实　Simon 重写 Datasette Lite，用 Service Worker 拦截页面和资源请求，再转给 Web Worker 内的 Pyodide/ASGI 应用。URL 可指定 Datasette commit、SQLite 版本、插件和数据，文章展示同一问题在修复前后的演示。
为何关注　复现材料从安装说明变成可直接打开的环境。多标签通过会话前缀分流；数据 URL 仍需 CORS，浏览器执行也有运行时限制。
CANN 启发（推断/建议）　可把算子测试元数据、性能 CSV 和版本比较做成浏览器演示，降低社区交流门槛；涉及 NPU 的 kernel 与运行时仍须在设备侧验证。

🌱 新兴生态

Inkling 2 Mini：权重复用不等于执行次数减少

2026-11-20 · 集成方发布介绍

已核事实　HF 介绍 Thinking Machines Lab 的多模态 MoE：约 26B 物理参数、每 token 激活约 3B，支持百万 token 上下文。24 个物理层中间 12 层循环三次，共 48 次层访问；每次访问保留各自 KV 与短卷积状态。
为何关注　循环结构节约权重存储，但计算、缓存和状态容量不能按物理层数直接估算。发布介绍列出 Transformers、llama.cpp、MLX 与 SGLang 接入，不等于其所有硬件后端均已支持。
CANN 启发（推断/建议）　适配评审需分别预算物理权重、逻辑层状态和循环通信；对 NVFP4/MXFP8 与 DSpark 逐路径确认。本期未发现 Inkling 2 Mini 首发 CANN 支持证据。

Genie 4：本周模型卡公开的能力与限制

2026-11-18 · 官方模型卡

已核事实　DeepMind 于 11 月 18 日发布的模型卡描述可同时生成音频与交互世界的 Genie 4，并明确长时间运行、复杂编辑或场景导航后细节及物体持久性可能漂移，物理、文字与空间准确性仍有限制。
为何关注　本条记录本周模型卡，不能把它当作该模型首次公布日期。世界模拟可提供 Agent 环境，但视听连贯不代表物理有效，训练数据价值还需独立验证。
CANN 启发（推断/建议）　若将世界模型用于昇腾具身训练的数据管线，可先固定动作、场景和评测种子，测长时一致性与跨域迁移，再算生成成本。未核实 CANN 部署支持。

MoE 专家流式加载：32GB Mac 上的工程实验

2026-11-18 · 一手工程实践

已核事实　Tarek Ziadé 将被路由选中的专家从 SSD 读入有界缓存，以槽位池复用 grouped_mm，并处理 Qwen3.8-Flash-Next 的 n-gram 表。其 M5 32GB 实验短 decode 为 13.9 token/s，Strata 为 14.8；通用实现仍以 Transformers PR #50717 提供反馈。
为何关注　文章保留了失败尝试和主机/GPU 等待分析。容量可运行不代表满足交互需求，作者也认为仍太慢；PR 实验不能写成已发布稳定功能，Mac 结果不能横推服务器。
CANN 启发（推断/建议）　昇腾 MoE 分层内存实验应分别测专家命中率、传输字节、主机同步和预取收益，并保留批量大小与模型格式，避免仅报可容纳参数量。
